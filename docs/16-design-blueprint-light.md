# ТЗ 16 — Редизайн Studio: «Blueprint Light»

Статус: спека для исполнения на ветке `feat/design-blueprint-light`. Исполнитель следует ей буквально; при неоднозначности — СТОП и вопрос, не импровизировать.

## 1. Цель

Полный ретейминг веб-Studio с тёмной «Deep Instrument» на светлую «Blueprint Light» — характер чистого инженерного чертежа: бумага, чертёжный синий, янтарные акценты предупреждений. Плюс полировка новых экранов (панель проверки импорта, share-экран, нормоконтроль) и общий проход по иерархии/плотности. Направление и палитра выбраны заказчиком (ui-ux-pro-max, стиль Data-Dense Dashboard).

## 2. Границы (нарушать нельзя)

- **Менять только**: `web/styles.css`, `web/app.js` (только цветовые константы и Plotly-конфиг, строки ~612–665), `web/index.html` (meta color-scheme, замена emoji-иконок на inline-SVG).
- **Не трогать**: `src/**` (в т.ч. `export/sld.py` — экспорт байт-детерминирован, тесты сравнивают побайтно), `api/**`, `tests/**`, логику app.js (обработчики, роутинг, localStorage, fetch).
- **Замороженный контракт**: имена CSS-переменных, все классы и id — НЕ переименовывать (app.js ссылается на них). Значения менять можно, новые токены добавлять можно. Внутренние JS-константы (`DARK` и т.п.) переименовывать можно.
- Шрифты остаются: Fira Sans (UI) + Fira Code (данные/моно).
- Русский язык UI-текстов не менять.

## 4. index.html

- `<meta name="color-scheme" content="dark">` → `light`.
- Кнопки с emoji (`✓ Нормоконтроль`, `📦 Пакет документов`, `🖨 Печать`, `🔗 Share-ссылка`) → inline-SVG иконки (стиль Lucide: stroke 1.9, 16px, `class="icon"`) + текст. Emoji в строках app.js, если есть, — тоже заменить (проверить grep'ом). Id/классы кнопок не менять; проверить, что app.js не перезаписывает innerHTML этих кнопок (если перезаписывает — SVG переносится в JS-шаблон).

## 6. Полировка экранов (в рамках новой темы)

1. **Панель проверки импорта** (`.import-review`): выровнять ритм заголовков h3, единые отступы 16/24, sticky-шапка предпросмотра на светлом, diff-строки R11 — чёткие статусные левые границы + светлые заливки. Чекбокс подтверждения — заметная янтарная плашка.
2. **Share-экран**: предупреждение (`.shared-warning`) — янтарная плашка в новой теме; бейдж READ-ONLY контрастный.
3. **Нормоконтроль** (`.norm-*`): карточки на белом с левой статусной границей 3px, hover — `--elev`; маркеры в таблице (box-shadow inset) сохранить с новыми цветами.
4. Таблица-щит: зебра не нужна, но hover-строка `--panel2`; sticky th на белом с нижней границей `--line-2`; статус-чипы `.st-cell` — светлые заливки (`*-soft`), тёмный статусный текст.
5. Карточки дашборда: убрать градиент на прозрачно-тёмный, белые карточки, левая синяя полоса при hover остаётся.

## 7. Доступность (обязательные проверки)

- Текст на всех поверхностях ≥4.5:1 (проверить хотя бы пары: `--dim` на `--bg`/`--panel`/`--panel2`; `--amber`-текст на своих плашках; `--acc-ink` на primary-кнопке).
- Статус не только цветом: точки/иконки в чипах сохранить.
- `prefers-reduced-motion` блок сохранить.
- Фокус-состояния видимы на светлом.
