# ТЗ 19 — Редизайн однолинейной схемы (эталон в прототипе)

Статус: спека для ветки `feat/ux-flows-prototype`. Скоуп — ТОЛЬКО клиентская схема в `web/prototype.js`; серверный генератор `src/electricopilot/export/sld.py` НЕ трогать (байт-детерминированные тесты) — перенос эталона на сервер будет отдельной фазой по решению заказчика. Заказчик отверг текущую схему: «по качеству ужасная».

## 1. Диагноз текущей схемы

Пустая простыня высотой в экран; подписи повёрнуты на 90° микрокеглем вдоль линий — нечитаемо; тонкие оранжевые линии без семантики цвета; символы аппаратов без номиналов рядом; штамп потерян внизу.

## 2. Целевой формат — классическая щитовая однолинейка

Формат проектной документации, родной для электрика: схема сверху, «паспорта» цепей колонками под ней, всё горизонтальным текстом.

### Компоновка (SVG, координаты фиксированные)
- Лист с тонкой рамкой (внутренние поля 24px). Общая высота схемы ≤ 560px при 4 цепях; ширина = 24 + N×190 + 24, при переполнении контейнера — горизонтальный скролл (как сейчас).
- **Ввод** слева сверху: символ вводного аппарата, подпись горизонтально: «Ввод · 400 В · 3ф · TN-C-S», ниже «Iрасч ≈ 33 А». 
- **Шина** — горизонтальная, толщиной 4px, цвет `--acc` (#1E40AF), от ввода через все отходящие линии.
- **Отходящая цепь** (шаг 190px): вертикальная линия 1.6px цветом `#0F1B33` длиной ~130px вниз от шины; на линии сверху вниз: символ автомата/предохранителя (IEC 60617, 22×34), символ УЗО если есть (под автоматом), стрелка нагрузки внизу. Ref цепи («L1») — горизонтально над шиной.

### «Паспорт» цепи (под стрелкой каждой цепи)
Колонка-таблица шириной 170px, горизонтальный текст, строки высотой 17px, разделители `--line`:
1. **L1 · Розетки кухни** (полужирно, 11.5px)
2. Автомат: «MCB 20 A · хар. C» / «Пред. gG 32 A» (словарь ТЗ 17)
3. УЗО: «RCBO 30 мА» или «—»
4. Кабель: «1P+N 2,5 мм² Cu/PVC · метод C»
5. «L = 18 м · IB = 16,8 А»
6. «ΔU = 2,26 % (из 5)»
7. Статус: цветной маркер-точка + «требует проверки» / пусто при норме (тихая норма, как в таблице щита)
Шрифт: Fira Sans 10.5–11.5px, данные — Fira Code. Никакого повёрнутого текста нигде.

### Цвет и статусы
- Линии/символы — `#0F1B33`; шина — `--acc`; фон листа белый.
- Статус цепи — ТОЛЬКО маркер в паспорте (цвета `--ok/--warn/--bad`), линии не перекрашивать. Оранжевый как цвет линий запрещён.

### Штамп
Компактный титульный блок в правом нижнем углу листа (3 строки: «Щит ВРУ-1 (пример) · DB-1», «Однолинейная схема · лист 1/1», «рекомендательно · не сертификация»), рамка 1px `--line-2`.
