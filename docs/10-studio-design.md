# 10 — ElectriCopilot Studio (аналог Claude Science для электрики)

Интерактивный веб-воркбенч поверх аудируемого ядра (`docs/00–09`). Ядро (движок + ревьюер +
провенанс + трасса) уже реализует «трудную» часть Claude Science; Studio добавляет **интерактивную
визуализацию, копилот-чат и рабочую среду специалиста**.

## 10.1 Маппинг Claude Science → Studio

| Claude Science | Studio |
|---|---|
| Координирующий агент + скиллы | Копилот (Gemini) + реестр скиллов (v1: подбор IEC 60364) |
| Агент-ревьюер (цитаты/расчёты) | `verify` (детерм. + Gemini Pro) + провенанс-гардрейл |
| Аудируемые артефакты (фигура+код+описание+история) | Каждая фигура несёт: расчёт, трассу, ссылки на нормы, входы |
| Нативный рендер (3D/треки) | **TCC-кривые**, однолинейка (SVG), свип, ΔU-профиль, дерейтинг |
| NL-правки фигур | Контролы + чат → пересчёт/перерисовка |
| Форк для сравнения | Сравнение сценариев (MCB↔gG, PVC↔XLPE) |
| Работает на вашей инфраструктуре | Бэкенд Python; ключ Gemini серверный |

## 10.2 Визуализации (данные считает бэкенд, детерминированно)

1. **TCC (время-токовая координация)** — log-log: полоса срабатывания аппарата
   (MCB B/C/D по IEC 60898, gG по IEC 60269) + кривая термостойкости кабеля (адиабатика
   `t=(k·S/I)²`, IEC 60364-4-43 §434.5.2) + маркеры IB и Iscc. Значения кривых **синтетические**,
   помечены; форма — по методологии.
2. **Свип сечения** — Iz(S) с линией требуемого Iz и выбранной точкой (governing).
3. **Профиль ΔU** — ΔU%(L) с линией предела; ползунок длины.
4. **Дерейтинг** — водопад It → ×ka → ×kg → Iz.
5. **Однолинейка (SVG)** — источник → аппарат → кабель → нагрузка, с подписями расчёта.

## 10.3 API (FastAPI, `studio_api.py`; ключ Gemini серверный)

```
GET  /api/health                        → {status, mode}
POST /api/size      SizingRequest        → SizingResult
POST /api/viz       SizingRequest        → {sweep, vd_profile, derating, tcc, sld} (детерм.)
POST /api/intake    {text}               → SizingRequest            (Gemini Flash)
POST /api/explain   SizingRequest        → {narrative, provenance}  (Gemini Flash)
POST /api/verify    SizingRequest        → VerificationVerdict      (Gemini Pro + детерм.)
```
Все ответы аудируемы: `viz`-данные несут `citations` и `data_provenance_note`.

## 10.4 Модель TCC (иллюстративная, помечена)

- **MCB:** тепловая обратнозависимая ветвь `t = Tth / ((I/In)² − 1)` на (1.2·In … mag) +
  магнитная (мгновенная) при `I ≥ mag·In` → `t≈0.01 с`; полоса B/C/D: mag∈{3–5, 5–10, 10–20}.
- **gG-предохранитель:** обратнозависимая `t = Tf · (In/I)^m` (иллюстративно), гейты 1.6·In.
- **Кабель:** `t = (k·S / I)²` (реальная адиабатика; k — синтетический из пакета).
- Координация видна: полоса аппарата ниже/левее кривой кабеля на [IB, Iscc].
- Параметры кривых — в норм-пакете (`trip_curves`), `source_note: SYNTHETIC`.

## 10.5 Фронтенд (SPA, без сборки)

`web/` — статический воркбенч: колонка цепей проекта · центральная панель артефактов
(вкладки TCC/Свип/ΔU/Однолинейка на Plotly+SVG) · правая панель копилот-чата и трассы.
Живые контролы → `/api/viz` пересчёт. Экспорт отчёта-артефакта (Markdown/print).
Библиотеки — Plotly.js по CDN; данных проекта в браузере (localStorage).

## 10.6 Деплой (Vercel)

Статический фронтенд + Python-serverless API (`api/index.py` оборачивает FastAPI). Секреты —
env Vercel (`OPENROUTER_API_KEY`). Neon-персистентность опциональна. Локально: `uvicorn`.

## 10.7 Границы v1

TCC/кривые аппаратов — иллюстративные (не замена каталогам производителей); одна цепь на
артефакт; проект/сценарии — в браузере; дисклеймер и подпись инженера сохраняются во всех
представлениях. Замена на лицензионные кривые — через норм-пакет, без правки кода.
