# 06 — Качество, тесты и золотые доменные кейсы

## 6.1 Что проверяем (и что НЕ проверяем)

- **Проверяем:** корректность **логики движка против поставляемого (синтетического) пакета** —
  при заданных значениях таблиц математика IB/In/IZ, поправок, координации, ВП и адиабатики
  верна; выбор `S` минимален и проходит все активные проверки; `governing_constraint`
  согласован; трасса и ссылки заполнены; гардрейлы срабатывают.
- **НЕ проверяем:** совпадение значений пакета с реальным IEC (значения синтетические,
  замена лицензионными данными — вне объёма, `04 §4.1`).

## 6.2 Уровни тестов

| Уровень | Файлы | Содержание |

| datapack | `tests/test_datapack.py` | загрузка/валидация, off-table → DataPackError, pack_key |
| e2e | `tests/test_e2e.py` + `electricopilot demo` | сквозной прогон в фолбэк-режиме, отчёт формируется |

Запуск: `uv run pytest`. E2E и все тесты **не требуют** ключей/БД (D8). Независимый оракул
`scripts/reference_calc.py` пересчитывает кейсы из синтетического пакета (второй источник эталонов).

## 6.3 Инварианты

- При `overall_status=PASS`: `IB ≤ In ≤ IZ` и `IZ ≥ (I2/In)/1.45·In` (для gG ⇒ `IZ ≥ 1.1034·In`).
- `IZ = It · ∏k` (сверка с точностью округления).
- Выбранное `S` реально проходит все активные проверки; `S` минимально в стандартном ряду.
- `governing_constraint ∈ {overload_coordination, voltage_drop, short_circuit}` = критерий,
  чей индивидуальный минимум сечения максимален (при равенстве приоритет: координация →
  КЗ → ВП).
- Каждый шаг трассы имеет ≥1 `Citation`; `signoff.status = UNSIGNED_ADVISORY` до подписи;
  `disclaimer` непуст; `data_provenance_note` непуста при `data_pack.status=illustrative`.

## 6.4 Золотые доменные кейсы (ручной расчёт = эталон)

Значения — из синтетического пакета (`04 §4.4`). `ρ_Cu=0.0225`, `λ=0.00008`, `k` синтетический.
`req_Iz = max(In, (I2/In)/1.45 · In)`.

### Кейс 1 — 1ф, координация перегрузки связывает → 4 мм², MCB 20 A
Вход: P=4600 Вт, U=230 В (1ф), cosφ=1.0, purpose=power; метод C, Cu, PVC, 2 жилы,
ambient=35 °C, группировка=1, L=25 м; MCB; I_scc=800 A, t=0.1 с.

- IB = 4600/230 = **20.0 A**;  In = наименьший ≥20 → **20 A** (MCB, I2/In=1.45).
- I2 = 1.45·20 = 29;  req_Iz = max(20, 29/1.45) = **20 A**.
- ka(PVC,35)=0.90, kg(1)=1.0, ∏k=**0.90**. Нужен It ≥ 20/0.90 = 22.22.
  C/Cu/PVC/2: 2.5→20 (20·0.9=18<20, нет), 4→30 (30·0.9=27≥20, да). **S=4 мм²**, It=30, IZ=**27.0 A**.
- Координация: 20≤20≤27 ✓; 29 ≤ 1.45·27=39.15 ✓.
- ВП: ΔU=2·20·25·(0.0225/4)=1000·0.005625=**5.62 В** → 5.62/230=**2.45 %** ≤5 ✓.
- Адиабатика: S_min=800·√0.1/120=**2.11 мм²** ≤4 ✓.
- **Итог:** S=4 мм², In=20 A, governing=`overload_coordination` (связал In≤IZ), PASS.

### Кейс 2 — 3ф, gG-предохранитель связывает выбор → 10 мм² (vs 6 мм² у MCB)
Вход: P=15000 Вт, U=400 В (3ф), cosφ=0.85; метод C, Cu, XLPE, 3 жилы, ambient=40 °C,
группировка=3, L=50 м; **gG_fuse**; I_scc=2500 A, t=0.1 с.

- IB = 15000/(√3·400·0.85) = **25.47 A**;  In = наименьший ≥25.47 → **32 A** (gG, I2/In=1.6).
- I2 = 1.6·32 = 51.2;  req_Iz = max(32, 51.2/1.45) = **35.31 A** (предохранитель связывает!).
- ka(XLPE,40)=0.90, kg(3)=0.75, ∏k=**0.675**. Нужен It ≥ 35.31/0.675 = 52.31.
  C/Cu/XLPE/3: 6→48 (48·0.675=32.4<35.31, нет), 10→66 (66·0.675=44.55≥35.31, да).
  **S=10 мм²**, It=66, IZ=**44.55 A**.
- Координация: 25.47≤32≤44.55 ✓; 51.2 ≤ 1.45·44.55=64.60 ✓.
- **Контраст:** тот же вход с **MCB** (I2/In=1.45) ⇒ req_Iz=32 ⇒ 6 мм² (48·0.675=32.4≥32, ✓)
  → **6 мм², IZ=32.40 A**. Предохранитель заставляет взять 10 мм² вместо 6 мм².
- ВП: sinφ=0.5268; term=0.0225·0.85/10+0.00008·0.5268=0.00195464;
  ΔU=√3·25.47·50·0.00195464=**4.31 В** → **1.08 %** ≤5 ✓.
- Адиабатика: S_min=2500·√0.1/150=**5.27 мм²** ≤10 ✓ (не связывает).
- **Итог:** S=10 мм², In=32 A (gG), governing=`overload_coordination` (связал I2-критерий), PASS.

### Кейс 3 — 1ф, падение напряжения связывает → 6 мм²
Вход: P=4600 Вт, U=230 В (1ф), cosφ=1.0; метод C, Cu, PVC, 2 жилы, ambient=30 °C,
группировка=1, **L=60 м**; MCB; I_scc=800 A, t=0.1 с.

- IB=**20.0 A**, In=**20 A**, req_Iz=**20 A**. ka(PVC,30)=1.0, kg=1.0, ∏k=1.0.
  Ампакитность: It≥20 ⇒ 2.5→20 (20·1.0=20≥20) ⇒ 2.5 мм² достаточно по току.
- ВП при 2.5 мм²: ΔU=2·20·60·(0.0225/2.5)=2400·0.009=**21.6 В** → 9.39 % ≫5 % (нет).
  Требуется %≤5: ΔU%=23.478/S; ≤5 ⇒ S≥4.70 ⇒ 4 мм² (5.87 %, нет), **6 мм²** (3.91 %, да).
- Адиабатика: 2.11 мм² ≤6 ✓. Координация при 6 мм²: IZ=40, 20≤20≤40 ✓.
- **Итог:** S=6 мм² (ампакитность дала бы 2.5), governing=`voltage_drop`, ВП=**3.91 %**, PASS.

### Кейс 4 — 3ф, термическая стойкость КЗ связывает → 70 мм²
Вход: I=100 A (задан ток), U=400 В (3ф), cosφ=0.9; метод C, Cu, XLPE, 3 жилы,
ambient=30 °C, группировка=1, L=30 м; MCB; **I_scc=20000 A, t=0.2 с**.

- IB=**100 A**, In=**100 A**, req_Iz=**100 A**. ∏k=1.0.
  Ампакитность: It≥100 ⇒ C/Cu/XLPE/3: 16→88 (нет), 25→120 (да) ⇒ 25 мм² достаточно по току.
- Адиабатика: S_min=20000·√0.2/150=**59.63 мм²** ⇒ требуется **70 мм²** (>25).
- ВП при 70 мм²: term=0.0225·0.9/70+0.00008·0.4359=0.00032416;
  ΔU=√3·100·30·0.00032416=**1.68 В** → **0.42 %** ≤5 ✓.
- Координация при 70 мм²: It=225, IZ=225, 100≤100≤225 ✓.
- **Итог:** S=70 мм² (ампакитность дала бы 25), governing=`short_circuit`,
  adiabatic_min=**59.63 мм²**, PASS.

## 6.6 Guardrail- и провенанс-тесты

- Нарратив с числом из трассы («4 мм²» в кейсе 1) → `provenance_ok=True`.
- Нарратив с «протащенным» числом («16 мм²», отсутствующим в кейсе 1) → `provenance_ok=False`,
  число в `unverified_numbers`; `apply_provenance_downgrade` возвращает копию с
  `overall_status='NEEDS_REVIEW'` (strict).
- `SignOff` обязателен, дефолт `UNSIGNED_ADVISORY`; `--sign` переводит в `SIGNED` и ставит
  `signed_at`; дисклеймер присутствует в Markdown.
- **Провенанс-нота (B12):** при `data_pack.status='illustrative'` `data_provenance_note`
  непуста и печатается в Markdown; при подмене `status='licensed'` — пуста и не печатается.
