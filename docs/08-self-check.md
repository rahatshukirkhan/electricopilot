## 8.1 Процесс

Спека 00–07 прошла **адверсариальное многоагентное ревью** (5 критиков + синтез):
доменная корректность (с независимым пересчётом всех золотых кейсов), полнота против
критериев приёмки, внутренняя непротиворечивость, копирайт/комплаенс, готовность контрактов
к параллельной реализации. Итог первого прохода: **NO-GO**, 29 findings. Ниже — их устранение.

## 8.7 Ре-ревью (второй проход)

Проведено адверсариальное ре-ревью двух блокер-классов на пропатченных доках (2 критика).
Итог: **обе линзы — GO, `blockers_closed=true`.** Остаточные пункты — только minor/nit,
устранены до заморозки:

- Копирайт: 3 точки поправок случайно совпадали с реальным IEC (XLPE 25 °C, kg 8/9) —
  сдвинуты (1.03 / 0.53 / 0.49); ряды `In`/сечений уточнены как **реальные** отраслевые
  факты (не синтетика; синтетика — только значения таблиц It/k/ka/kg).
- Контракт: заморожен `CitationKey` (Literal); `DEFAULT_PACK_PATH` резолвится через
  `importlib.resources`; объявлены исключения (`electricopilot.exceptions`); `reference_ambient_c`
  помечен как air-reference-only (v1); зафиксирована кардинальность `checks` (всегда 3, пропуск
  КЗ → `passed=True` + warning).

**Спека ЗАМОРОЖЕНА.** Этап 2 реализует контракты 03 буквально; отклонение — только через
