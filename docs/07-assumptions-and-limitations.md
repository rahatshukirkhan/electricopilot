# 07 — Допущения и ограничения

## 7.1 Допущения (зафиксированы письменно, по требованию брифа)

| # | Допущение | Почему / влияние |
|---|---|---|
| A1 | Значения норм-пакета — **синтетические** (не из IEC), ненормативные. | Копирайт IEC; замена лицензионными данными без правки кода (`04 §4.1`). |
| A2 | `voltage_v` = 230 В (1ф, L-N) и 400 В (3ф, L-L, линейное). | Стандартная НН Европа/СНГ; настраивается во вводе. |
| A3 | Падение напряжения — установившийся режим. | Пусковые просадки двигателей вне v1 (`01 §1.6`). |
| A4 | Опорные условия поправок: воздух 30 °C, земля 20 °C. | Соответствует таблицам IEC 60364-5-52; поправки без опоры бессмысленны. |
| A5 | `ρ` — «в эксплуатации» (≈1.25× при 20 °C): Cu 0.0225, Al 0.036 Ω·мм²/м. | Консервативная оценка ВП по практике CENELEC. |
| A6 | `λ` (реактанс) = 0.00008 Ω/м, единый. | Типовой многожильный НН; для точности заменяется по кабелю. |
| A7 | Число нагруженных жил: 1ф→2, 3ф→3, если не задано явно. | Влияет на выбор столбца таблицы It. |
| A8 | Время отключения `t` по умолчанию 0.1 с, если не задано. | Разумно для быстрых аппаратов; переопределяется. |
| A9 | Ряды In и сечений — дискретные из пакета. | Реальный выбор аппаратуры дискретен. |
| A10 | I2/In: MCB 1.45, MCCB 1.30, gG 1.60. | Классовые значения; gG связывает выбор (`01 §1.5`). |

## 7.2 Ограничения объёма v1 (НЕ реализуется, зафиксировано)

| # | Ограничение | Последствие / что нужно для снятия |
|---|---|---|
| L1 | Нет расчёта ADS/Zs (петля «фаза-нуль», время отключения по Zs). | Только адиабатика по КЗ. Для ADS нужен импеданс сети/петли. |
| L2 | Нет пусковых токов двигателей, селективности, каскада. | Двигательные цепи считаются как обычная нагрузка по IB. |
| L3 | Нет модели теплового сопротивления грунта (метод D — только таблицы-заглушки). | Для полноценного D нужны ρ_грунта и глубина. |
| L4 | Нет гармоник/нагрузки нейтрали, параллельных кабелей, разной загрузки в пучке. | Однозначная 2/3-жильная модель. |
| L5 | Значения таблиц синтетические, не соответствуют реальному IEC. | Нужны лицензионные данные (A1); PASS/FAIL — арифметика на синтетике. |
| L6 | Живые LLM-роли требуют `OPENROUTER_API_KEY`; без него — фолбэк. | NL-разбор и LLM-нарратив/критика недоступны без ключа. |
| L7 | Персистентность в Neon требует `DATABASE_URL`; иначе — JSONL. | Апгрейд, не блокер (D8/D9). |

## 7.3 Регуляторная позиция

Система **рекомендательная**. Она не выпускает сертификаты и не заменяет инженера.
Каждый результат несёт `SignOff` со статусом `UNSIGNED_ADVISORY` по умолчанию и дисклеймер.
Ответственность за применение — на квалифицированном инженере, который проверяет и подписывает.

## 7.4 Известные риски и их снятие

| Риск | Снятие |
|---|---|
| LLM «протащит» неверное число в объяснение. | Гардрейл числового провенанса + strict-режим (`05 §5.3`). |
| Пользователь примет иллюстративные числа за нормативные. | Явная пометка `illustrative` в отчёте/README + дисклеймер (`04 §4.2`). |
| Молчаливый фолбэк маскирует misconfig модели. | `LlmConfigError` при неизвестном slug'е (D10). |
| Некорректный ввод «угадывается». | Строгая валидация enum'ов, отказ с перечислением допустимого (`02 §2.6`). |
